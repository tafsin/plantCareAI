# Google authentication branding

`google_g.png` is the unmodified official Google G downloaded from
https://developers.google.com/static/identity/images/g-logo.png on 2026-09-04.
Its use follows https://developers.google.com/identity/branding-guidelines.
Google's trademarks remain Google's property.

`google_sans.ttf` is Google Sans Medium, distributed by Google Fonts:
https://fonts.googleapis.com/css2?family=Google+Sans:wght@500
The accompanying `OFL.txt` was retrieved from the Google Fonts download
manifest for Google Sans. The font is used only for the Google button.
